# Проект 7-го спринта: Геоаналитика соцсети с Apache Spark

## 📋 Описание проекта

Проектирование и реализация ETL-пайплайна для геоаналитики данных социальной сети.  
Пайплайн обрабатывает события пользователей (сообщения, подписки, реакции, регистрации), определяет геолокацию событий и строит витрины для бизнес-аналитики и системы рекомендаций друзей.

## 🎯 Бизнес-задачи

1. **Геоаналитика аудитории**: определить, где находится большинство пользователей по количеству сообщений, лайков и подписок.
2. **Рекомендация друзей**: предлагать пользователю написать человеку, если они состоят в одном канале, раньше не переписывались и находятся не дальше 1 км друг от друга.
3. **Анализ путешествий**: определить, как часто пользователи путешествуют и какие города выбирают.

## 🏗 Архитектура решения

```
Parquet-файлы (Data Lake)
    ↓
Apache Spark (PySpark)
    ↓
Витрины данных (Parquet)
    ↓
Apache Airflow (оркестрация)
```

### Витрины данных

| Витрина | Описание | Файл |
|---------|----------|------|
| **user_geo** | Профиль пользователя: актуальный город, домашний город, статистика путешествий, локальное время | `mart1_usergeo.py` |
| **zone_geo** | Статистика событий по зонам (городам): количество сообщений, подписок, реакций за неделю и месяц | `mart2_zone_geo.py` |
| **recommendations** | Рекомендации друзей: пользователи из одного канала в радиусе 1 км, не переписывавшиеся ранее | `mart3_recommend.py` |

## 📊 Бизнес-логика витрин

### Витрина 1: user_geo
- **act_city** — город последнего сообщения пользователя
- **home_city** — город, где пользователь провёл 27+ дней (разница между первым и последним днём)
- **travel_count** — количество посещённых городов
- **travel_array** — массив городов в порядке посещения
- **local_time** — локальное время последнего сообщения

### Витрина 2: zone_geo
- Агрегация событий (message, subscription, reaction, register) по городам
- Окна: неделя и месяц
- Метрики: количество событий каждого типа

### Витрина 3: recommendations
- **Условия**: общий канал, не переписывались ранее, расстояние ≤ 1 км
- **Алгоритм**: подписки на канал → кросс-джойн пользователей → фильтрация по расстоянию

## 🔧 Ключевые технические решения

- **Паттерн Template Method**: `BaseMart` определяет скелет ETL (`extract` → `transform` → `load`), конкретные витрины реализуют шаги
- **Геовычисления**: формула Хаверсина для расстояния между координатами
- **Оконные функции Spark**: `row_number()`, `lag()`, `datediff()` для анализа временных рядов
- **Broadcast-переменные**: оптимизация join с небольшим справочником городов
- **Airflow + SparkSubmitOperator**: запуск Spark-заданий через Airflow с параметризацией

## 🚀 Как запустить

```bash
# 1. Клонировать репозиторий
git clone https://github.com/drobvital/de-project-sprint-7.git
cd de-project-sprint-7

# 2. Установить зависимости
pip install pyspark apache-airflow

# 3. Запустить витрину локально (пример для user_geo)
python src/scripts/mart1_usergeo.py \
    "/path/to/events" \
    "/path/to/geo.parquet" \
    "/path/to/output" \
    27 \
    "yyyy-MM-dd HH:mm:ss"

# 4. Запустить DAG в Airflow
airflow dags trigger geo_marts_dag
```
