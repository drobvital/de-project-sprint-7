# Проект 7-го спринта: ETL-пайплайн с Apache Airflow

## 📋 Описание проекта

Проектирование и реализация ETL-пайплайна для аналитического хранилища данных социальной сети. 
Пайплайн загружает данные из S3 в Vertica, строит многослойное DWH (STG → DDS → CDM) и формирует витрины для бизнес-аналитики.

## 🎯 Бизнес-задача

Маркетологи соцсети хотят размещать рекламу на сторонних площадках. Для этого нужно определить группы с высокой конверсией в первое сообщение — паблики, которые лучше всего вовлекают новых участников.

## 🏗 Архитектура решения

```
S3 (Yandex Cloud) 
    ↓
STG-слой (сырые данные)
    ↓
DDS-слой (Data Vault 2.0: хабы, сателлиты, линки)
    ↓
CDM-слой (витрины для бизнеса)
    ↓
Отчёт: конверсия в первое сообщение по группам
```

## 📊 Ключевые метрики

- **10+ групп** проанализировано на конверсию
- **3 слоя данных**: STG → DDS → CDM
- **4 типа сущностей** в Data Vault: хабы, сателлиты, линки, справочники

## 🚀 Как запустить

```bash
# 1. Клонировать репозиторий
git clone https://github.com/drobvital/de-project-sprint-7.git
cd de-project-sprint-7

# 2. Запустить инфраструктуру
docker-compose up -d

# 3. Инициализировать Airflow
airflow db init

# 4. Запустить DAG
airflow dags trigger s3_to_stg
```

## 📈 Результат

SQL-запрос, который выводит по 10 самым старым группам:
- Количество новых пользователей (`cnt_added_users`)
- Количество активных пользователей (`cnt_users_in_group_with_messages`)
- Конверсию в первое сообщение (`group_conversion`)
